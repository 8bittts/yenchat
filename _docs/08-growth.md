# Growth

Discovery and measurement for yen.chat.

## Measurement

YEN has no product analytics, accounts, license server, or revenue.
`/download` redirects to the current DMG on GitHub Releases and records nothing.
The website runs Vercel Web Analytics and Speed Insights only; the custom events are listed in [09-quality.md](09-quality.md).
Never add a download counter, a growth database, or an owner report without an explicit operator request and a privacy-policy update in the same change.

## Public discovery

The homepage contains the product overview and complete field guide.
Terms combines the terms of service, privacy policy, and cookie policy.
The sitemap lists these two pages.
The separate blog hosts articles and release notes.
Former documentation, comparison, use-case, Tunes, and library URLs redirect to the homepage.

The optional desktop token menu reads local tool records.
Its readings never enter website analytics.
