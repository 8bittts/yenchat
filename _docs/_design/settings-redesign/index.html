What every view removes

  • Search. Five panes and 36 rows fit on screen; nothing is deep enough to hunt for.
  • Import and Export. config.yen is already a portable text file.
  • Per-pane Reset. One Reset All Settings row remains, in General.
  • The Close button and the footer status bar. The window closes like any other, and feedback sits beside the control it describes.
  • The shortcut filter field. Five category tabs replace it.
  • Layout tiles. They are actions, and they stay in the File menu and the command palette.
  • The sound search popover and per-stream volume. A pop-up button lists the 14 system sounds; volume follows the system.
  • Window Border scope, radius, two palette menus, outline style and the preview strip. A switch, a color choice and a weight remain.
  • Separate X and Y padding with a slider, a field and a stepper each. One Padding stepper remains.
  • The Local Speech re-check button. Status refreshes on its own.

Reviewed against Apple's current guidance

ElementGuidanceIn the redesign
GlassLiquid Glass forms the navigation and control layer. Do not use it in the content layer.Glass on the toolbar, sidebar, inspector and dock only. Forms use a standard material.
WindowTitle names the visible pane. Minimize and zoom are dimmed. Reopen on the last pane.All three views follow it; A uses the toolbar of panes the HIG describes.
FormsGrouped forms with taller rows, rounder sections, title-style section headers.46 pt rows, 16 pt section corners, concentric with a 26 pt window corner.
ControlsRounder standard controls. Use color sparingly so controls stay legible.Capsule switches, sliders, segmented controls and pop-up buttons. One accent color.
HierarchyUse a checkbox or indentation for dependent settings.Dependent rows are indented and appear only when their parent is on.
HelpTooltips stay under 75 characters. Essential text belongs in the interface.One short line under a label where a setting needs it. No tooltips carry meaning.
Accessibility4.5:1 text contrast. Never signal by color alone. Avoid timed messages.Status uses a dot plus a word in a label color. No auto-dismissing footer.
